# Create a [strollur object](https://mothur.org/strollur/reference/strollur.html) object with 500 sequences

Create a [strollur
object](https://mothur.org/strollur/reference/strollur.html) object with
500 sequences

## Usage

``` r
strollur_multi_sample_small()
```

## Value

[strollur object](https://mothur.org/strollur/reference/strollur.html)
with 500 sequences

## Examples

``` r
rchime::strollur_multi_sample_small()
#> Added 500 sequences.
#> Assigned 500 sequence abundances.
```
